### Hi, I'm Ram

I build automation for work that people repeat every day: web portals, spreadsheets, documents and maps. Based in Jaipur.

Most of what I make runs quietly in the background. It reads a sheet, walks through a portal the way a careful person would, pulls data out of messy documents, or answers a question from a map pin.

**Some things I've built**

- **Portal entry runner**: one spreadsheet in, hundreds of cases walked through an 8-step web workflow. Plain Python and `requests`, resumable, tested against a mock portal.
- **Agent workflow for data extraction**: 965 records pulled out of 19 document formats by agents working in parallel, with a rule that a blank beats a guess.
- **Land rate from a map pin**: Rajasthan's government land rates, searchable offline and answered from a coordinate using ArcGIS polygons and SQLite.
- **Portal auto-fill**: a Chrome extension that fills eight different lender portals from a finished Excel file.
- **Auction map**: three auction sites scraped each morning and scored against the district median, shown on a Leaflet map.

The code for most of these belongs to the teams I built them for, so the details and screenshots live on my site.
